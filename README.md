# SWYNEX – E-commerce Data Cleaning & Preparation

## Project Overview
This project was completed as part of SWYNEX Internship Task 1 – Data Cleaning & Preparation.

The objective was to clean and prepare an e-commerce dataset for further analysis.

## Tool Used
- Microsoft Excel

## Data Cleaning Performed
- Removed duplicate records
- Handled missing City values
- Handled missing Payment Method values
- Standardized payment method values
- Corrected inconsistent product names
- Standardized category names
- Removed unnecessary spaces
- Corrected invalid quantity values
- Corrected negative price values
- Standardized price format
- Standardized order date format
- Performed a final data quality check

## Dataset
The cleaned dataset contains 10,000+ e-commerce order records.

## Output
The cleaned dataset is available in:
`Ecommerce_Cleaned.xlsx`
